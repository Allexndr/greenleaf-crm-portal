# Быстрый старт - Greenleaf Registration System

## 🚀 Установка и запуск

### 1. Установка зависимостей
```bash
npm install
```

### 2. Настройка базы данных
```bash
# Генерация Prisma клиента
npx prisma generate

# Создание базы данных
npx prisma db push

# Инициализация тестовых данных
npm run db:init
```

### 3. Запуск приложения
```bash
npm run dev
```

Приложение будет доступно по адресу: `http://localhost:3000`

## 📱 Использование

### Для клиентов
1. Перейдите по ссылке сервисного центра
2. Нажмите "Подать заявку"
3. Заполните форму регистрации
4. Получите номер заявки
5. Используйте "Статус заявки" для проверки

### Для администраторов
1. Перейдите на `http://localhost:3000/admin/login`
2. Войдите с тестовыми данными
3. Управляйте заявками, сервисными центрами и пользователями

## 🛠️ Разработка

### Полезные команды
```bash
# Запуск в режиме разработки
npm run dev

# Просмотр базы данных
npm run db:studio

# Сброс базы данных
npx prisma db push --force-reset
npm run db:init

# Сборка для production
npm run build
npm start
```

### Структура проекта
- `app/` - Next.js App Router (страницы и API)
- `components/` - React компоненты
- `lib/` - Утилиты и конфигурация
- `prisma/` - Схема базы данных
- `scripts/` - Скрипты инициализации

## 🔧 Настройка

### Переменные окружения
Создайте файл `.env.local` на основе `env.example`:

```env
DATABASE_URL="file:./dev.db"
JWT_SECRET="your-secret-key"
DEFAULT_TEMP_PASSWORD="Aa12345"
```

### Изменение паролей по умолчанию
В файле `scripts/init-db.js` измените пароли:
```javascript
const hashedPassword = await bcrypt.hash('your-password', 12);
```

## 📊 Мониторинг

### Логи
- Все действия пользователей записываются в таблицу `AuditLog`
- Ошибки отображаются в консоли браузера и сервера

### Статистика
- В админ-панели доступна статистика по заявкам
- Экспорт данных в XLSX формате

## 🚨 Устранение неполадок

### База данных не создается
```bash
npx prisma generate
npx prisma db push
```

### Ошибки аутентификации
Проверьте JWT_SECRET в `.env.local`

### Проблемы с зависимостями
```bash
rm -rf node_modules package-lock.json
npm install
```

## 📞 Поддержка

При возникновении проблем:
1. Проверьте логи в консоли
2. Убедитесь, что все зависимости установлены
3. Проверьте настройки базы данных
4. Обратитесь к администратору системы

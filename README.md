# Greenleaf Registration System

Система подачи заявок на регистрацию в Greenleaf с модерацией, выдачей логина и пароля через портал статусов и управлением потоком утверждений.

## Функциональность

### Для клиентов
- Подача заявки на регистрацию через уникальную ссылку сервисного центра
- Проверка статуса заявки по номеру заявки и телефону
- Получение логина и временного пароля при утверждении

### Для администраторов
- **Админ сайта (уровень 0)**: управление сервисными центрами и глобальными настройками
- **Админ сервисного центра (уровень 1)**: управление пользователями/менеджерами своего центра
- **Менеджер/модератор (уровень 2)**: работа с заявками без доступа к учётным данным центра

### Основные возможности
- Система ролей и разграничения доступа
- Управление заявками с фильтрацией и поиском
- Экспорт данных в XLSX
- Аудит действий пользователей
- Интеграция с Greenleaf API
- Очередь обработки заявок
- Цветовая индикация доверия по способу оплаты

## Технологии

- **Frontend**: Next.js 14, React, TypeScript, Tailwind CSS
- **Backend**: Next.js API Routes
- **База данных**: SQLite с Prisma ORM
- **Аутентификация**: JWT токены
- **Валидация**: Zod
- **UI компоненты**: Custom components с Tailwind CSS

## Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd greenleaf-registration-system
```

2. Установите зависимости:
```bash
npm install
```

3. Настройте переменные окружения:
```bash
cp env.example .env.local
```

Отредактируйте `.env.local`:
```env
# Database
DATABASE_URL="file:./dev.db"

# JWT Secret
JWT_SECRET="your-super-secret-jwt-key-here"

# NextAuth
NEXTAUTH_URL="http://localhost:3000"
NEXTAUTH_SECRET="your-nextauth-secret-here"

# Greenleaf API
GREENLEAF_API_URL="https://greenleaf-global.com/api"
GREENLEAF_API_KEY="your-greenleaf-api-key"

# File Upload
UPLOAD_DIR="./uploads"
MAX_FILE_SIZE="5242880" # 5MB

# System Settings
DEFAULT_TEMP_PASSWORD="Aa12345"
PROCESSING_INTERVAL="30000" # 30 seconds in milliseconds
```

4. Инициализируйте базу данных:
```bash
npx prisma generate
npx prisma db push
```

5. Создайте первого администратора:
```bash
npx prisma studio
```

Откройте Prisma Studio и создайте пользователя с ролью `SITE_ADMIN` в таблице `User`.

6. Запустите приложение:
```bash
npm run dev
```

Приложение будет доступно по адресу `http://localhost:3000`.

## Использование

### Создание сервисного центра

1. Войдите в админ-панель как администратор сайта
2. Перейдите в "Сервисные центры"
3. Нажмите "Добавить центр"
4. Заполните данные:
   - Номер центра (например, S240350)
   - Описание
   - Адрес
   - Учётные данные Greenleaf (опционально)
5. Сохраните

### Подача заявки клиентом

1. Клиент переходит по ссылке `http://localhost:3000/?sc=<service-center-id>`
2. Нажимает "Подать заявку"
3. Заполняет форму с данными:
   - Личные данные (имя, фамилия, телефон, email)
   - Данные Greenleaf (спонсор, размещение, номер удостоверения)
   - Способ оплаты и область размещения
4. Получает номер заявки

### Проверка статуса

1. Клиент переходит в "Статус заявки"
2. Вводит номер заявки и телефон
3. Видит текущий статус и данные для входа (при утверждении)

### Модерация заявок

1. Менеджер заходит в админ-панель
2. Переходит в "Заявки"
3. Может фильтровать и искать заявки
4. Открывает заявку для просмотра деталей
5. Принимает решение: утвердить, отклонить или взять на рассмотрение

## API Endpoints

### Публичные
- `GET /` - Главная страница
- `GET /register` - Форма регистрации
- `GET /status` - Портал статусов
- `POST /api/applications/submit` - Подача заявки
- `POST /api/applications/status` - Проверка статуса

### Админ
- `GET /admin` - Панель администратора
- `GET /api/admin/applications` - Список заявок
- `GET /api/admin/applications/[id]` - Детали заявки
- `PATCH /api/admin/applications/[id]/status` - Изменение статуса
- `GET /api/admin/service-centers` - Список сервисных центров
- `POST /api/admin/service-centers` - Создание сервисного центра

## Развертывание

### Production

1. Настройте переменные окружения для production
2. Используйте PostgreSQL вместо SQLite:
```env
DATABASE_URL="postgresql://username:password@localhost:5432/greenleaf_db"
```

3. Соберите приложение:
```bash
npm run build
```

4. Запустите:
```bash
npm start
```

### Docker

```dockerfile
FROM node:18-alpine
WORKDIR /app
COPY package*.json ./
RUN npm ci --only=production
COPY . .
RUN npm run build
EXPOSE 3000
CMD ["npm", "start"]
```
